# W105: a step's style differs from its relation's style

A `~>` step over a `->` relation, or a `->` step over a `~>` relation, means the scenario and the relations disagree about whether the caller waits.

## Failing example

```saxl
system Shop
service Web
queue Jobs
Web -> Jobs
scenario order {
  Web ~> Jobs : enqueue
}
```

## Fixed example

```saxl
system Shop
service Web
queue Jobs
Web ~> Jobs
scenario order {
  Web ~> Jobs : enqueue
}
```
