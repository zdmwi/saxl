# W102: every workload is in a single region

If every workload runs in one region, a regional outage takes the whole system down. Deploy to a second region, or allow the warning with a reason.

## Failing example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web x2
  }
}
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web x2
  }
}
allow W102 "single region is fine for the prototype"
```
