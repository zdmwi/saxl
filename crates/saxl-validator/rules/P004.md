# P004: description string on a relation chain

A chain such as `A -> B -> C` declares several relations, so it is unclear which one a description belongs to. Only single-hop relations take a description.

## Failing example

```saxl
system Shop
actor Buyer
service Web
store DB
Buyer -> Web -> DB "checkout"
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
store DB
Buyer -> Web "checkout"
Web -> DB
```
