# E005: a data placement names the wrong kind of element

`in` and `cached` targets must be stores. In `via Q -> S`, `Q` must be a queue and `S` a store.

In a library, a type lives `in` the api or module that owns it. Libraries have no stores or queues, so `cached` and `via` are not allowed there.

## Failing example

```saxl
system Shop
service Web
data Order in Web { id, total }
```

## Fixed example

```saxl
system Shop
service Web
store DB
Web -> DB
data Order in DB { id, total }
```
