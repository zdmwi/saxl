# I201: a single-replica service takes part in synchronous calls

Callers wait on a synchronous call, so a service with one replica (and no autoscaling) that takes part in one is a single point of failure.

## Failing example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web x1
  }
}
scenario browse {
  Buyer -> Web
}
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web x2
  }
}
scenario browse {
  Buyer -> Web
}
```
