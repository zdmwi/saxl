# W107: synchronous calls form a cycle

A cycle of `->` calls can deadlock or recurse without bound. The primary label is the first relation of the cycle; secondary labels mark the rest. Make one of the calls asynchronous or remove it.

## Failing example

```saxl
system Shop
service Orders
service Billing
Orders -> Billing
Billing -> Orders
```

## Fixed example

```saxl
system Shop
service Orders
service Billing
Orders -> Billing
Billing ~> Orders
```
