# P003: unclosed `{` at end of file

A block opened with `{` was never closed. The label points at the opening brace.

## Failing example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web
  }
```

## Fixed example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web
  }
}
```
