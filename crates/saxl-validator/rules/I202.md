# I202: a hook has no implementation inside the library

If no api or module implements a hook, every consumer has to write one before the library works. That can be intended, as with plugin hooks; say so with `allow I202`.

## Failing example

```saxl
library Quill
api to_html
hook Highlighter
to_html -> Highlighter
```

## Fixed example

```saxl
library Quill
api to_html
module plain
hook Highlighter
to_html -> Highlighter
plain impl Highlighter
```
