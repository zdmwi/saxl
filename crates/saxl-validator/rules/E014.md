# E014: two elements' `at` patterns match the same file

Each file should belong to one element, so a later check can tell which element an import comes from. saxl compares the patterns as written: a path against a pattern, two equal patterns, or `dir/**` against anything inside `dir/`.

## Failing example

```saxl
library Quill
api parse at "src/**"
module escape at "src/escape.rs"
parse -> escape
```

## Fixed example

```saxl
library Quill
api parse at "src/parse.rs"
module escape at "src/escape.rs"
parse -> escape
```
