# E012: a consumer calls something that is not an `api`

Consumers may only call a library's public API. A call to a module reaches into internals that can change without notice.

## Failing example

```saxl
library Quill
consumer App
api parse
module blocks
App -> parse
App -> blocks
parse -> blocks
```

## Fixed example

```saxl
library Quill
consumer App
api parse
module blocks
App -> parse
parse -> blocks
```
