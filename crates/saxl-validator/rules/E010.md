# E010: `allow` names an error or unknown code

Only warnings (`W`) and infos (`I`) can be allowed. Errors (`E`) and parse errors (`P`) must be fixed, and unknown codes are reported so typos don't silently allow nothing.

## Failing example

```saxl
system Shop
allow E006 "scenarios are drafts"
```

## Fixed example

```saxl
system Shop
allow W102 "single region is fine for now"
```
