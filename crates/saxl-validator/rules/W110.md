# W110: a library's api or module is in no package

Every api and module should ship in some package listed in a `publish` block. This is the library counterpart of W101.

## Failing example

```saxl
library Quill
api parse
module lexer
parse -> lexer
publish "crates.io" {
  crate quill {
    parse
  }
}
```

## Fixed example

```saxl
library Quill
api parse
module lexer
parse -> lexer
publish "crates.io" {
  crate quill {
    parse, lexer
  }
}
```
