# E006: a scenario step has no matching relation

Every `->` or `~>` hop in a scenario must follow a declared relation between the same two elements (in either style; a style mismatch is W105). Infrastructure nodes are removed from the hop list first. Replies (`-->`) are checked by E007 instead.

## Failing example

```saxl
system Shop
actor Buyer
service Web
external Email
Buyer -> Web
scenario order {
  Buyer -> Web
  Web ~> Email : receipt
}
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
external Email
Buyer -> Web
Web ~> Email
scenario order {
  Buyer -> Web
  Web ~> Email : receipt
}
```
