# W108: unknown deployment attribute

The v1 attributes are `xN` (replica count), `autoscale`, and `primary+replica`.

## Failing example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x2 spot
  }
}
```

## Fixed example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x2
  }
}
```
