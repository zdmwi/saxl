# W108: unknown deployment or publish attribute

In a `deploy` block the attributes are `xN` (replica count), `autoscale`, and `primary+replica`. In a `publish` block the only attribute is `feature <name>`.

## Failing example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x2 spot
  }
}
```

## Fixed example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x2
  }
}
```
