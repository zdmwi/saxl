# W104: an element takes part in no relation, data placement, or scenario

An element that nothing refers to is usually left over from an earlier design. Implementing a hook counts as a use of the implementor, but a hook that nothing calls is unused.

## Failing example

```saxl
system Shop
actor Buyer
service Web
service Legacy
Buyer -> Web
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
```
