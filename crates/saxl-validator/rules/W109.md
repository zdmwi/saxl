# W109: a module depends on one gated behind a feature it is not gated on

When both ends of a relation ship in the same package, a module built without feature `f` must not depend on one built only with `f`. The build passes with default features and fails for anyone who turns `f` off. Depend on a hook instead, and let the gated module implement it.

## Failing example

```saxl
library Quill
api to_html
module highlight
to_html -> highlight
publish "crates.io" {
  crate quill {
    to_html
    highlight feature syntect
  }
}
```

## Fixed example

```saxl
library Quill
api to_html
module highlight
hook Highlighter
to_html -> Highlighter
highlight impl Highlighter
publish "crates.io" {
  crate quill {
    to_html
    highlight feature syntect
  }
}
```
