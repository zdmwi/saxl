# E007: a reply has no matching open call

A reply `B --> A` closes an earlier call `A -> B` in the same scenario. Replies to calls that were never made, or that were already answered, are errors. Inside `parallel`, each branch starts with the calls open before the block.

## Failing example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
scenario order {
  Web --> Buyer : 200
}
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
scenario order {
  Buyer -> Web
  Web --> Buyer : 200
}
```
