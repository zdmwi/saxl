# E009: an element is deployed twice in one region

Deploy an element once per region and scale it with a replica count.

## Failing example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web
  }
  cluster spare {
    Web
  }
}
```

## Fixed example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x2
  }
}
```
