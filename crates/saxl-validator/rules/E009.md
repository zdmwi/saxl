# E009: an element is deployed twice in one region, or published twice

Deploy an element once per region and scale it with a replica count.

In a library, list each element once per package, and put each module in exactly one package. An api may appear in several packages, because a package can re-export it.

## Failing example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web
  }
  cluster spare {
    Web
  }
}
```

## Fixed example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x2
  }
}
```
