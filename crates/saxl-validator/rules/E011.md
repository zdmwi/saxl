# E011: an infrastructure node is used where an element is required

Infrastructure nodes such as `cdn` exist so scenarios can show requests passing through them. They can't be used in relations, data placements, or deployment workloads, and can't start or end a scenario step.

## Failing example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Edge
deploy region eu {
  cdn Edge
  cluster main {
    Web
  }
}
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cdn Edge
  cluster main {
    Web
  }
}
scenario browse {
  Buyer -> Edge -> Web
}
```
