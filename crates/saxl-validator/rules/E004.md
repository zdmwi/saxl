# E004: a relation connects two outside elements

A relation between two actors or externals says nothing about the system being described. Route it through an element inside the system.

## Failing example

```saxl
system Shop
actor Buyer
external Payments
Buyer -> Payments
```

## Fixed example

```saxl
system Shop
actor Buyer
external Payments
service Web
Buyer -> Web
Web -> Payments
```
