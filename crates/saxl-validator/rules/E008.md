# E008: an element outside the system or library is deployed or published

Actors and externals run outside the system, so they can't be deployed. In a library, consumers, packages, and hooks are not the library's code, so they can't be listed in a `publish` block.

## Failing example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web, Buyer
  }
}
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web
  }
}
```
