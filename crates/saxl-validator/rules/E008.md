# E008: an actor or external appears in a deployment

Actors and externals run outside the system, so they can't be deployed.

## Failing example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web, Buyer
  }
}
```

## Fixed example

```saxl
system Shop
actor Buyer
service Web
Buyer -> Web
deploy region eu {
  cluster main {
    Web
  }
}
```
