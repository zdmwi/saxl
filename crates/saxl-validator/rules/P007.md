# P007: malformed replica count

A replica count is `x` followed by a positive number with no leading zeros, such as `x3`.

## Failing example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x0
  }
}
```

## Fixed example

```saxl
system Shop
service Web
deploy region eu {
  cluster main {
    Web x2
  }
}
```
