# E013: an `impl` statement names the wrong kind of element

`A impl H` says that `A` provides an implementation of hook `H`. `H` must be a hook, and `A` must be an api, a module, or a consumer.

## Failing example

```saxl
library Quill
api parse
module ast
parse -> ast
parse impl ast
```

## Fixed example

```saxl
library Quill
api parse
hook Highlighter
parse -> Highlighter
parse impl Highlighter
```
