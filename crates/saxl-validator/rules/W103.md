# W103: a source-of-truth store has no `primary+replica`

A store that is the source of truth for some data should survive the loss of one node. Mark its workload `primary+replica` in at least one region.

## Failing example

```saxl
system Shop
service Web
store DB
Web -> DB
data Order in DB { id }
deploy region eu {
  cluster main {
    Web
  }
  managed {
    DB
  }
}
```

## Fixed example

```saxl
system Shop
service Web
store DB
Web -> DB
data Order in DB { id }
deploy region eu {
  cluster main {
    Web
  }
  managed {
    DB primary+replica
  }
}
```
